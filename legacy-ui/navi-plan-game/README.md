# Navi Plan legacy UI reference

These files were preserved from `BilalAli1-code/navi-plan-game` at commit
`0eb6abfdafde14a6fedd06f3a8b0f75dc9f58870` during the ProjectSim 2 repository migration.

They are retained as a **visual and interaction reference only**:

- reusable colors, typography, spacing, cards, badges, layouts, responsive patterns, icons, and assets may be adapted;
- legacy simulation state, `useSim()` behavior, client-side progress or decision calculations, routes, Supabase/Lovable integrations, and backend logic must not become authoritative;
- active product behavior remains in the ProjectSim 2 Domain, Application, Infrastructure, API, projection, and `apps/web` boundaries.

Use the migration matrix in
`docs/business-cases/12-legacy-visual-transfer/` when adapting these visuals into active ProjectSim 2 surfaces.

This folder defines **projection contracts and consistency rules** for the learner workplace, plus follow-on implementation notes for shared infrastructure, workplace surfaces through Activities and Completed History, production relay / projection operations (PS-023), and the unified convergence suite (PS-024).

PS-024 is validation/test infrastructure only — it does not add learner features.

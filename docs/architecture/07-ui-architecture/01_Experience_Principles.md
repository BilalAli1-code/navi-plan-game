# Experience Principles

**Document ID:** PS-UI-001  
**Version:** 1.0  
**Status:** Approved

## 1. Make the Next Action Clear

The current priority, blocker, or decision must be visible without requiring the learner to inspect every tab.

## 2. Preserve Context

Users should understand why an activity exists, what changed, and how it relates to the project.

## 3. Show Consequences

Decisions must visibly connect to project, stakeholder, and learning outcomes.

## 4. Avoid Duplicate Truth

Counts, statuses, progress, and achievements must come from shared projections.

## 5. Separate Work from Learning

Operational actions and coaching may appear together, but their roles must remain distinct.

## 6. Preserve History

Emails, meetings, conversations, commitments, and decisions remain available after completion.

## 7. Reduce Cognitive Load

Prioritize required actions, collapse secondary information, and use progressive disclosure.

## 8. Make AI Transparent

AI-generated content must be labeled and should never appear as authoritative system truth.

## 9. Support Reflection

The experience should create intentional pauses for explanation, feedback, and learning transfer.

## 10. Design for Real Work Patterns

The interface should feel like a professional project workspace, not a quiz application.

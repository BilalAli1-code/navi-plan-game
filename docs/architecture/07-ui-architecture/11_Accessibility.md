# Accessibility

**Document ID:** PS-UI-011  
**Version:** 1.0  
**Status:** Approved

## Target

ProjectSim targets WCAG 2.2 AA.

## Requirements

- Keyboard operability
- Visible focus
- Semantic landmarks
- Logical heading structure
- Accessible names
- Sufficient contrast
- Error identification
- Status announcements
- Reduced-motion support
- Screen-reader-friendly tables and charts
- Captioned media
- Accessible authentication

## Simulation-Specific Requirements

1. Timed pressure must not create inaccessible barriers.
2. Critical information is not conveyed only by animation or color.
3. Stakeholder sentiment includes text.
4. Progress bars expose numeric values.
5. Decision consequences are announced after submission.
6. New messages do not steal focus unexpectedly.
7. Drag-and-drop features include keyboard alternatives.
8. Maya chat supports screen-reader navigation.
9. Archived history remains navigable.
10. Accessibility checks are part of Definition of Done.

## Testing

- Automated accessibility tests
- Keyboard-only tests
- Screen-reader smoke tests
- Zoom and reflow tests
- Color-contrast checks
- Reduced-motion checks
- Manual critical-journey review

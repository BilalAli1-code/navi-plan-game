# Learning Experience Architecture

**Document ID:** PS-UI-006  
**Version:** 1.0  
**Status:** Approved

## Experience Areas

- Daily Briefing
- Learning Objectives
- PMBOK Reinforcement
- Reflection
- Competency Progress
- Practice Questions
- Exam Readiness
- Coaching History
- Achievements
- Final Learning Report

## Separation of Concerns

```text
Simulation Outcome ≠ Learning Outcome
Project Performance ≠ Mastery
AI Feedback ≠ Authoritative Competency State
```

## Rules

1. Competency changes include supporting evidence.
2. Reflections remain visible after submission.
3. Exam readiness shows confidence and coverage.
4. Achievements do not replace meaningful feedback.
5. Learning content is contextual to the current scenario.
6. Practice recommendations derive from documented weaknesses.
7. The interface distinguishes completion from mastery.
8. Final reports explain both project results and learning results.
9. Coaching should not reveal future scenario answers.
10. Learners can revisit prior feedback and evidence.

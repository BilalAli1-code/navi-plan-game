# ProjectSim 2.0 Engineering Blueprint

ProjectSim 2.0 is an AI-powered project leadership simulation platform for experiential learning, professional development, and PMP preparation.

This repository contains the official product, domain, architecture, engineering, and implementation documentation for ProjectSim 2.0.

## Purpose

The Engineering Blueprint is the single source of truth for product direction, domain language, architecture, database design, APIs, AI behavior, UI contracts, testing, deployment, and engineering standards.

## Governing Principles

1. One authoritative simulation runtime.
2. One source of truth for every business value.
3. UI renders projections; it does not calculate business state.
4. AI assists but never owns authoritative state.
5. Published content is immutable and versioned.
6. Every important decision is documented.
7. Every invariant is testable.

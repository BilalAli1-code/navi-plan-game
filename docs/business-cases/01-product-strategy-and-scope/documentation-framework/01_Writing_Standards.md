# Writing Standards

**Document ID:** PS-HBK-001  
**Version:** 1.0  
**Status:** Approved

## Rules

- Use direct language.
- Define terms before using them.
- Use `must` for mandatory rules, `should` for preferred rules, and `may` for optional behavior.
- Keep one authoritative definition per term.
- Prefer Mermaid for diagrams and TypeScript for conceptual contracts.
- Use stable requirement IDs such as `FR-001`, `NFR-001`, `INV-SIM-001`, and `ADR-001`.

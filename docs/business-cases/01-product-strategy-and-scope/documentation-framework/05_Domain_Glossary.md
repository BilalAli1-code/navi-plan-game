# Domain Glossary

**Document ID:** PS-HBK-005  
**Version:** 1.0  
**Status:** Approved

### Learning Program
A structured learning experience containing one or more Business Cases.

### Business Case
A reusable project scenario containing versioned simulation content.

### Content Package
The publishable aggregate containing all definitions required to execute a Business Case.

### Simulation Run
One learner's unique execution of one published Content Package version.

### Simulation Runtime
The execution layer responsible for sequencing, idempotency, replay, checkpoints, and orchestration.

### Core Simulation
The domain authority for project state, consequences, progress, and completion.

### Projection
A read-only, rebuildable model optimized for a specific interface.

### Maya
ProjectSim's non-authoritative AI coaching persona.

# Naming Conventions

**Document ID:** PS-HBK-003  
**Version:** 1.0  
**Status:** Approved

## Documents

Use ordered names such as `01_Product_Vision.md`.

## Domain Types

Use singular PascalCase names such as `SimulationRun`, `StakeholderRelationship`, and `LearningObjective`.

## Commands and Events

Commands use business intent: `StartSimulationRun`, `SubmitDecision`, `CompleteActivity`.

Events use past tense: `SimulationRunStarted`, `DecisionResolved`, `ActivityCompleted`.
